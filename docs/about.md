## 项目定位

Mioku 是一个插件式的机器人框架，围绕 Agent 能力构建。框架自身提供事件、Bot 连接、插件加载与服务管理，AI 能力、截图、配置等则以服务的形式按需装配，插件可以自由组合这些能力。

Mioku 取名自带初音未来主题：名字里藏着 Miku，同时代表开源 (Open) ~~和某神人韩国网红没有关系~~。

## 碎碎念

- Mioku 作为一个个人的、轻量的框架，和 NoneBot、AstrBot 这些大框架在功能完善度和社区规模上自然没得比，但 Mioku 启动快、写插件简单、插件好分发、内存占用低……这些已经够了。
- 得益于 TypeScript 的类型定义，AI 生成的插件可用率较高。你可以用任意 Vibe Coding 工具（Codex、Claude Code、OpenCode 等），简单描述你想要的插件功能，让 AI 帮你实现
